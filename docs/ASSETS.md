# VASSEL visual assets

The website uses the supplied Vassel logo and eleven optimized WebP campaign and catalogue visuals. The palette combines ivory, espresso, cognac and warm architectural light.

| Asset | Use |
| --- | --- |
| `vassel-campaign.webp` | Homepage campaign and Maison |
| `vassel-signature.webp` | Signature handbag and editorial |
| `vassel-atelier.webp` | Atelier and craftsmanship |
| `vassel-lookbook.webp` | Ready-to-wear editorial |
| `vassel-arche.webp` | Arche handbag |
| `vassel-sella.webp` | Sella handbag |
| `vassel-raffia.webp` | Raffia handbag |
| `vassel-cuff.webp` | Accessories |
| `vassel-shirt.webp` | Shirts |
| `vassel-jacket.webp` | Outerwear |
| `vassel-trousers.webp` | Trousers |

Images live in `public/images/`. The original logo PNG and lossless WebP are in `public/brand/`. The favicon uses the same original artwork.

Catalogue imagery illustrates the collection direction. Product photos, colour variants, materials and measurements must be verified against the final products. Images can be replaced in the admin product editor; homepage imagery is managed in Homepage. Uploads accept JPG, PNG and WebP up to 5 MB.

README screenshots are in `docs/screenshots/`. Local test captures and database files are excluded from version control.
